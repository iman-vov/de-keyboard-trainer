# de-keyboard-trainer — правила розробки

## Стек
- Phaser 3 + Vite (vanilla JavaScript, без TypeScript)
- localStorage для прогресу (без бекенду, без сервера)
- Без UI-фреймворків (без React, Vue, Angular)

---

## Жорсткі правила

### Код
- Не додавати функції поза поточним завданням фази
- Не рефакторити код, що не є частиною задачі
- Не додавати коментарі — тільки там, де WHY неочевидний
- Не додавати error handling для сценаріїв, що не можуть статися
- Не будувати абстракції наперед — тільки те, що потрібно зараз
- Три схожі рядки — краще ніж передчасна абстракція

### Розкладка клавіатури
- Основна: German QWERTZ (ä ö ü ß включно — обов'язково)
- Додаткові: RU, UK — тільки після повного завершення DE-функціоналу
- Не плутати QWERTY та QWERTZ (y↔z переставлені)
- Джерело правди для розкладки: `src/data/qwertz.js`

### Геймплей / UX — КРИТИЧНО
- Дитина НІКОЛИ не бачить "Game Over", "Невдача", "Спробуй ще раз" як покарання
- Помилка = персонаж спотикається і продовжує, гра не зупиняється
- Наступний рівень завжди доступний незалежно від результату
- Час на реакцію: мінімум 3 секунди на літеру в перших рівнях
- Екранна клавіатура ЗАВЖДИ відображається (у перших 2 фазах — з підсвіткою)
- Позитивне підкріплення: анімація + звук на кожне правильне натискання

### Графіка та ассети
- Всі ассети в `/assets/[category]/` — не розкидати по інших місцях
- Не писати код із заглушками "TODO: замінити спрайт" — використовувати або реальний ассет, або чіткий плейсхолдер з визначеними розмірами
- Генерація: ChatGPT DALL-E 3 (персонажі, фони) + kenney.nl (UI)
- Формат спрайтів: PNG з прозорим фоном

### Локалізація
- i18n через простий JS-об'єкт `src/utils/i18n.js` — без сторонніх бібліотек
- Весь текст UI — тільки через ключі локалізації, нікого хардкодити
- DE — primary і default, RU/UK — secondary
- Локалі: `src/data/locales/de.json`, `ru.json`, `uk.json`

### Прогрес (localStorage)
- Ключ: `kbd-trainer-progress`
- Структура: `{ lang, completedLevels[], stars{levelId: 1|2|3}, unlockedPlanets[] }`
- Не зберігати особисті дані користувача
